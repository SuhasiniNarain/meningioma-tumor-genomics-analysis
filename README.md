# meningioma-tumor-genomics-analysis
SQL and Python-based clinical genomics analysis of Meningioma dataset from cBioPortal
Meningioma Tumor Genomics Analysis using SQL & Python
Project Overview

This project focuses on the analysis of a Meningioma clinical genomics dataset obtained from cBioPortal for Cancer Genomics.

The objective was to explore clinical and genomic patterns using SQL and Python, including mutation burden, tumor recurrence, WHO grade distribution, and molecular subgroups.
Dataset Source
Dataset: Meningioma (University of Toronto, Nature 2021)
Source: cBioPortal for Cancer Genomics
